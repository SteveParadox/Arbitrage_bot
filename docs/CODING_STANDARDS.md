# Coding Standards

## Python

Use Python 3.12+, type hints, Ruff, pytest, small modules, and dependency injection around exchange clients.

## Rust

Use stable Rust, rustfmt, Clippy with warnings denied, explicit error handling, and tests for order-book/risk invariants.

## TypeScript

Use strict TypeScript, React functional components, ESLint, and typed API contracts.

## General

Keep credentials out of code and logs. Prefer deterministic tests. Separate strategy decisions from exchange transport. Document public interfaces and non-obvious risk assumptions.
